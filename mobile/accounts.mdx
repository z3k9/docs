L'onglet **Comptes** répertorie tous les comptes liés à votre organisation.

## Consulter vos comptes

Chaque compte s'affiche sous forme de carte indiquant :

- Le nom du compte et les quatre derniers chiffres du numéro de compte
- Le **Solde disponible** en grands caractères, avec le **Solde** (solde comptable) en dessous
- La devise du compte (par exemple USD ou CDF)

Appuyez sur l'icône en forme d'œil d'une carte pour masquer ou afficher son solde.

## Consulter l'activité d'un compte

Sélectionnez **Appuyez pour afficher l'activité** sous un compte pour ouvrir l'historique de ses transactions.

Utilisez les onglets pour filtrer la liste :

| Onglet | Affiche |
|---|---|
| **All** | Toutes les transactions du compte |
| **Credit** | Les fonds reçus |
| **Debit** | Les fonds envoyés ou prélevés |
| **Pending** | Les transactions non encore comptabilisées |

Utilisez l'icône de filtre à droite pour accéder à d'autres options.

<Tip>
Pour obtenir un relevé officiel sur une période donnée, utilisez les [Relevés](/mobile/more).
</Tip>
