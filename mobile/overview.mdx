L'application mobile CIB met les comptes de votre entreprise dans votre poche. Les agents peuvent consulter les soldes, initier des virements et approuver les éléments en attente dans les files, le tout depuis un téléphone.

L'application est disponible en anglais et en français, avec un thème clair et un thème sombre.

## Se repérer dans l'application

Une barre de navigation se trouve en bas de chaque écran principal :

| Onglet | Ce qu'il ouvre |
|---|---|
| **Accueil** | Votre tableau de bord : soldes, taux de change, approbations et activité récente |
| **Comptes** | La liste des comptes de votre organisation |
| **Payer** | Le menu **Transférer de l'argent**, qui regroupe tous les types de virement |
| **Approbations** | La file d'attente des transactions et l'**Activity Queue**. Un badge rouge indique le nombre d'éléments en attente. |
| **Plus** | Votre profil, **Bénéficiaires**, **Relevés**, **Équipe**, **Paramètres**, **Support**, la langue et la déconnexion |

## Avant de commencer

<Check>Vous disposez d'un profil d'agent actif sur First Bank DRC CIB. Consultez [Agents](/web-portal/administration/officers).</Check>
<Check>Vous connaissez l'adresse e-mail et le mot de passe de votre profil CIB.</Check>

<Note>
Les virements que vous initiez dans l'application mobile suivent les mêmes règles d'approbation que sur le Portail Web. Ils sont placés dans la file d'attente des transactions et doivent être approuvés par un Autorisateur avant que la banque ne les traite.
</Note>
