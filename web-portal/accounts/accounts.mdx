La page Comptes vous offre une vue consolidée de tous les comptes détenus par votre organisation, avec les soldes répartis par devise.

## Cartes récapitulatives

| Carte | Affiche |
|---|---|
| **Solde disponible total** | Solde disponible combiné de tous les comptes, avec le nombre de comptes |
| **Solde comptable total** | Solde comptable combiné de tous les comptes |
| **Solde CDF** | Solde total détenu sur les comptes en franc congolais |
| **Solde USD** | Solde total détenu sur les comptes en dollar américain |

## Tableau Mes comptes

Chaque ligne affiche le Numéro de compte, le Nom du compte, le Type (par ex. Courant), la Devise, le Solde disponible, le Solde comptable et le Statut (par ex. Actif). Utilisez l'icône de visualisation dans la colonne Actions pour voir plus de détails sur un compte précis.

<Note>
L'affichage de la liste peut basculer entre une disposition en tableau et une disposition en cartes à l'aide des icônes de vue au-dessus du tableau. Les commandes d'actualisation, de filtre et de téléchargement sont également disponibles.
</Note>
