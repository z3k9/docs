La page Transactions affiche l'historique complet de l'activité sur vos comptes, avec des totaux cumulés pour le volume, les encaissements et les décaissements.

## Cartes récapitulatives

| Carte | Affiche |
|---|---|
| **Volume total** | Valeur combinée de toutes les transactions |
| **Encaissements totaux** | Crédits cumulés depuis toujours |
| **Décaissements totaux** | Débits cumulés depuis toujours |

## Tableau Historique des transactions

Chaque ligne affiche la Date de transaction, le Numéro de compte, le Nom du compte, la Référence de transaction, le Montant et un indicateur **D/C** signalant si l'écriture est un Débit ou un Crédit. Le tableau est paginé et affiche un nombre défini de transactions par page.
